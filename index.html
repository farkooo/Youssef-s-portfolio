Engineering Perspective

I'm a Junior Data Engineer and Communication and Information Engineering student (Year 2) focused on building reliable data solutions and turning raw data into dependable business assets.

I work mainly with Python and SQL for data cleaning, data quality, ETL/ELT pipelines, data warehousing, and dimensional modeling. Through hands-on projects, I've applied these skills to real-world data challenges, including building an end-to-end data warehouse using SQL Server and handling messy multi-source datasets.

I approach data engineering from a practical perspective: understanding the data, identifying the problems, and building reliable workflows that make data clean, consistent, structured, and ready for analytics and reporting.
